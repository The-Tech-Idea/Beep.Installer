### Tabs

| Tab | Purpose |
|---|---|
| **Project** | Project name, product, version, publisher, support URL, default install path, start menu folder, install type, admin requirement, license text |
| **Files & Payload** | Source directory browser, recursive scan toggle, file tree, include/exclude patterns, file count + size |
| **Components** | List view of components with up/down ordering; per-component property grid (id, name, description, size, required, selected, install type, depends, conflicts); "Edit Files" opens `ComponentFilesDialog` |
| **Prerequisites** | List view; add/remove prerequisites (id, name, version, command/pattern detection, download URL, mandatory flag) |
| **Shortcuts** | List view; add/remove shortcuts (name, target, location, subfolder) |
| **Registry** | List view; add/remove registry entries (key path, value name, value, kind) |
| **Branding** | Window title, welcome title, publisher name/URL/email, icon path, banner path, theme (Modern/Classic/Compact), show EULA, allow component selection, allow path change |
| **Wizard Pages** | Checked list of wizard pages (Welcome, License, InstallType, Components, Folder, StartMenu, Tasks, PerUser/Machine, Prerequisites, Ready, Progress, Complete) |
| **Build** | Output directory, output filename, setup icon, architecture, payload compression + level, uninstall entry, restore point, self-contained, scope selection, default scope, code signing |
| **Build Log** | Live log of build steps with progress bar |

### Wizard navigation

Each form uses a `List<IInstallerPage>` with `NavigateTo(int index)` and `CapturePageState()` to pull state from each page into the shared `InstallContext` before advancing.

| Method | Purpose |
|---|---|
| `OnEnter(ctx)` | Called when the page is shown — populates UI from context |
| `Validate()` | Returns whether Next button should be enabled |
| `CanGoNext` (property) | Same — checked by the wizard shell |
| `ValidityChanged` event | Fired when page validity changes (e.g. license accepted) |
| `CapturePageState()` (wizard shell) | Reads public properties from each page into the shared `InstallContext` |

### Install execution

On clicking "Install":
1. Capture all page state
2. Build `SetupContext` with config + path + flags
3. Build `SetupWizard` with steps: `PrerequisiteCheck` → `DirectoryCreate` → `FileCopy` → `ShortcutCreate` → `RegistryWrite` → `VerifyInstall`
4. Run on thread pool; marshal `Progress<PassedArgs>` back to UI thread
5. Show `CompletePage` with success/failure + log path

## Phase 05 — Wizard Pages

| # | Page | Purpose | Key controls | Validation |
|---|---|---|---|---|
| 1 | `WelcomePage` | Intro screen | Title, version, description | Always OK |
| 2 | `LicensePage` | EULA | RTF viewer, accept/decline radio | Must accept |
| 3 | `ComponentSelectionPage` | Feature picker | Tree with checkboxes, size + description panel, dependency enforcement | At least one selected (always) |
| 4 | `FolderPage` | Install path | TextBox, Browse, disk-space info, per-user toggle | Path must be valid |
| 5 | `StartMenuPage` | Start menu folder | TextBox, "don't create" checkbox | Optional |
| 6 | `AdditionalTasksPage` | Desktop icon, autostart, file assoc | Checkboxes | Optional |
| 7 | `ReadyPage` | Pre-install summary | Read-only summary text | Always OK |
| 8 | `CompletePage` | Success/failure | Result icon, message, launch + view-log checkboxes | Last page |

### `IInstallerPage` interface

```csharp
public interface IInstallerPage
{
    string PageTitle { get; }
    string Subtitle { get; }
    bool CanGoNext { get; }
    void OnEnter(InstallContext ctx);
    bool Validate();
    event EventHandler<bool>? ValidityChanged;
}

public class InstallContext
{
    public InstallConfig Config { get; set; }
    public string InstallPath { get; set; }
    public bool AcceptLicense { get; set; }
    public bool CreateDesktopIcon { get; set; }
    public bool CreateStartMenu { get; set; }
    public bool AutoStart { get; set; }
    public bool PerUser { get; set; }
    public string StartMenuFolder { get; set; }
    public InstallationType InstallType { get; set; }
    public Dictionary<string, object> Bag { get; }
    public long EstimatedSizeBytes { get; }  // sum of Selected||Required sizes
}
```

### Component dependency handling

`ComponentSelectionPage` enforces:
- `Required` components cannot be unchecked (forced back to checked)
- Checking a component auto-checks its `DependsOn` dependencies
- Unchecking a component unchecks its dependents

Recursive `AfterCheck` events are suppressed via a `_suppressEvents` flag to prevent stack overflow.
