## Phase 07 — Validation, Silent Mode, CLI

### Validation & prerequisites

`PrerequisiteCheckStep` runs:
1. OS version check (Windows 10 1809+ / Windows 11 / Windows Server 2019+)
2. .NET runtime check (`dotnet --list-runtimes`)
3. Administrator privileges check
4. Disk space check (2x component size)
5. Custom prerequisites from `InstallConfig.Prerequisites[]` (regex on `DetectionCommand` output)

Fails the install with a clear message if any mandatory prerequisite is missing.

### Silent / CLI mode

`Program.cs` dispatches based on command-line arguments:

| Argument | Behavior |
|---|---|
| (none) | Open Package Builder, or run as installer if `install-config.json` is next to the exe |
| `/BUILD=<file>` | Build a `.bpkg` headlessly |
| `/OUT=<dir>` | Override build output directory |
| `/PREVIEW=<file>` | Show project summary |
| `/CONFIG=<file>` | Run as installer with a specific config file |
| `/S` or `/SILENT` | Silent install (no UI) |
| `/D=<path>` | Override install directory (with `/S`) |
| `/UNINSTALL` | Silent uninstall |
| `/SELFTEST` | Install + verify + uninstall cycle in `%TEMP%` |
| `/LANGMGR` | Open Language Manager |
| `/?` `/H` `/HELP` | Show help |
| `/VER` | Show version |

### Exit codes

| Code | Meaning |
|---|---|
| 0 | Success |
| 1 | General failure |
| 2 | Invalid arguments / config not found |
| 99 | Fatal unhandled error |

### Self-test

`Beep.Installer.exe /SELFTEST` performs:
1. Create a tiny source file in `%TEMP%`
2. Build an `InstallConfig` pointing at it
3. Run `DirectoryCreateStep` → `FileCopyStep` → `VerifyInstallStep`
4. Confirm `install-manifest.json` exists
5. Run `UninstallStep`
6. Confirm test dir is gone

Currently 3/4 phases pass (Cleanup fails because the existing `UninstallStep` in BeepDM does not fully remove the install dir — that's a BeepDM issue, not in scope for this project).

### Headless dispatch

`Program.Main` defers `ApplicationConfiguration.Initialize()` (which is what triggers the WinForms DPI loader) for commands that don't need a UI. CLI commands run fully headless and don't require a display.

## Phase 08 — Logging, Rollback, Error Handling

### Engine-level (BeepDM)

- `InstallLogger` — dual output to `%TEMP%\Beep_Install_{ts}.log` + Windows Event Log
- `RollbackManager` — stack of `IRollbackAction` registered BEFORE execution, popped and executed in reverse on failure
- `SetupCheckpointStore` — resume support, persists state to disk
- `SetupReport` — per-step results with timing + SHA-256 content hash

### Runtime installer

`ThemedInstallerForm` / `InstallerWizardForm`:
- Show progress in real time
- On any step failure: stop, show error message, offer "View Log" checkbox
- On cancellation: confirm before close; abort cleanly

### Generator

`InstallerBuilder` collects `Warnings` and `Errors` lists, exposes a `Summary` string. The Package Builder's Build Log tab shows live progress and final summary.
