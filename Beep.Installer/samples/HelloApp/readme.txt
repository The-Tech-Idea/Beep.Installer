MyApp 1.0
==========

This is a sample application to demonstrate Beep Installer.

After installing, you can find:
- MyApp.exe (the launcher batch file) in the chosen install directory
- A shortcut on the Start Menu under "Beep Samples\MyApp"
- A desktop shortcut

Files in this sample:
- MyApp.bat          - sample launcher
- readme.txt         - this file
- docs\help.txt      - sample documentation
