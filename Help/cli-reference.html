CLI Reference

Every verb Beep.Installer.exe understands. Verbs are dispatched in Program.cs; headless verbs run fully without a UI.

Authoring & build

CommandEffect
/BUILD=<project.bsetup> [/OUT=dir]Build the installer headlessly (Track A). /FORMAT=msix|msixbundle|exe selects Track C.
/REQUIRESIGNEDCI gate — refuse to produce an unsigned build (exit 1).
/VALIDATE=<project.bsetup>Validate a project without building.
/PREVIEW=<project.bsetup>Print a project summary.
/PUBLISH=<project.bsetup> [/OUT=dir] [/UPDATEURL=url] [/NOSIGN]Publish as ClickOnce (Track B).
/BUILD=<p> /PUBLISHFEED=<dir> [/FEEDURL=url] [/CHANNEL=x] [/MINVERSION=x.y.z] [/REPUBLISH]Build then stage into a static update feed.

Runtime (shipped installer)

CommandEffect
/S · /SILENT · /VERYSILENTSilent install. Inno Setup grammar, so Intune/SCCM/winget scripts work unchanged.
/D=<path>Override the install directory.
/COMPONENTS=a,bSelect components for a silent install.
/FORCEAllow installing an older version over a newer one (downgrade).
/NORESTART · /RESTARTEXITCODE=nSuppress / override the reboot-required exit code (default 3010).
/UNINSTALL [/D=path]Silent uninstall (used by Add/Remove Programs).
/REPAIR [/D=path]Restore missing or modified files from the payload.
/SELFTESTInstall → verify → uninstall in %TEMP%; exit 0 on success.
/LOG=<path>Write the install log to a chosen file (default announced, recorded in ARP).

App self-update

CommandEffect
/CHECKUPDATE [/FEED=url]Report whether an app or module update is available.
/UPDATE [/FEED=url] [/D=root]Apply an available app update side-by-side.

Exit codes

CodeMeaning
0Success.
3010Success — a reboot is required (MSI convention; deployment tooling understands it).
1Failure.
2Bad input (missing/invalid script).
