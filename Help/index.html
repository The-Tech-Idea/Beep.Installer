Beep Installer

A multi-model installer generator and self-update system for .NET desktop apps — one .bsetup project, three output shapes, and a complete app-update stack.

Overview

Beep.Installer is a .NET 10 (WinForms) installer generator that targets parity with Inno Setup, ClickOnce, NSIS, WiX/MSI and Squirrel/Velopack. A single human-editable .bsetup project builds into three output shapes:

  • Track A — a self-contained Setup.exe with an embedded payload and an install wizard (Inno/NSIS style).
  • Track B — a ClickOnce publish folder with manifests and .deploy files.
  • Track C — an .msix package for the Microsoft Store / MSIX.

The same Beep.Installer.exe is both the generator and the Track-A runtime. Beyond installing, the system ships a full app self-update stack (TheTechIdea.Beep.Updates): a static hash-verified feed, delta and side-by-side updates, feed-pinned NuGet module updates, drop-in WinForms/WPF update UI, and an optional update server with staged rollout, telemetry and an admin dashboard.

🚀 Quick Start

Build an installer, then give the app self-update — in a few lines.

Architecture Build Pipeline App Updates

Build & publish

# Build a self-contained Setup.exe from a .bsetup project
Beep.Installer.exe /BUILD=MyApp.bsetup /OUT=out

# Build and stage into a static update feed (for self-update)
Beep.Installer.exe /BUILD=MyApp.bsetup /PUBLISHFEED=\\host\feed /FEEDURL=https://updates.example.com

Give the app self-update

// WinForms — one call shows an "update available" dialog with progress
await BeepUpdater.CheckAndPromptAsync(this, new UpdateSettings {
    FeedUrl        = "https://updates.example.com/stable/feed.json?cid=" + machineId,
    CurrentVersion = "1.2.0",
    InstallRoot    = Application.StartupPath
});
